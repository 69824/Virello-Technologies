VIRELLO TECHNOLOGIES - SCHEME OF WORK FILE UPLOAD SETUP

This version keeps Firestore for Scheme of Work data but uses Cloudinary for optional PDF/DOC/DOCX attachments. Firebase Storage is no longer used by the Scheme of Work feature.

1. Create/sign in to a Cloudinary account.
2. In Cloudinary Console, open Settings > Upload > Upload Presets.
3. Create a new upload preset and set it to Unsigned.
4. For safety, restrict the preset to the file types you want and set a maximum raw file size of 10 MB.
5. Copy your Cloud Name and the unsigned Upload Preset name.
6. Open js/cloudinary-config.js.
7. Replace:
   YOUR_CLOUD_NAME
   YOUR_UNSIGNED_UPLOAD_PRESET
   with your real values.
8. Do NOT put your Cloudinary API Secret in the website.
9. Run the project normally.

If Cloudinary is not configured, the Scheme of Work can still be created/saved/submitted without an attachment.

The current maximum attachment size in the app is 10 MB. Cloudinary's current Free plan lists a 10 MB maximum raw file size.
